🇱🇰 Explore Sri Lanka - Vibe Travel Guide
An interactive, responsive single-page web application designed to showcase Sri Lanka's top travel destinations, luxury & eco stays, dynamic travel budget estimation, and live map interaction.
🌟 Key Features
🗺️ Interactive Leaflet.js Map: Custom interactive map featuring top hotspots across Sri Lanka (Sigiriya, Ella, Kandy, Mirissa, Galle Fort, Yala, etc.) with custom markers and destination details.
🏨 Accommodation Directory: Filterable hotels and eco-lodges by stay tier (Luxury, Boutique, Eco-Lodge, Budget) and location with real-time room rate display.
💱 Multi-Currency Support: Instant toggle between USD ($) and LKR (Rs) across hotel pricing and budget calculations.
💡 Interactive Budget Estimator: Dynamic cost calculator tailored for daily accommodation tiers, dining choices, local transit (Tuk-Tuk, trains), and excursion entries.
🎨 Modern Tropical UI/UX: Styled with Tailwind CSS, custom glassmorphism design, and mobile-responsive drawer navigation.
🛠️ Tech Stack & Libraries
Frontend: HTML5, Modern Vanilla JavaScript (ES6+)
Styling: Tailwind CSS (CDN)
Interactive Maps: Leaflet.js
Iconography: FontAwesome 6
Typography: Google Fonts (Plus Jakarta Sans & Playfair Display)
Hosting: GitHub Pages
